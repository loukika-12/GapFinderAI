# Sample Syllabus: Introduction to Data Science

**Purpose:** Safe, small sample syllabus for evaluator walkthroughs and manual testing. It is committed as sample content; it is not automatically uploaded to a user's account.

## Unit 1 — Foundations
- What is data science?
- Data lifecycle: collect, clean, explore, communicate
- Structured and unstructured data
- Types of variables and measurement scales

## Unit 2 — Python and Data Handling
- Python data types and control flow
- Lists, dictionaries, functions
- NumPy arrays and vectorized operations
- Pandas Series and DataFrames
- Missing values, duplicates, and data type conversion

## Unit 3 — Exploratory Data Analysis
- Descriptive statistics: mean, median, mode, variance, standard deviation
- Frequency tables and distributions
- Outliers and missingness
- Data visualization and chart selection
- Correlation versus causation

## Unit 4 — Introductory Machine Learning
- Features and labels
- Train/test split
- Classification versus regression
- Overfitting and generalization
- Accuracy, precision, recall, and F1 score

## Unit 5 — Communicating Insights
- Framing an analytical question
- Choosing useful metrics
- Explaining uncertainty and limitations
- Building a clear data story

## Suggested diagnostic blueprint
- 2 questions from Foundations
- 3 questions from Python/Data Handling
- 2 questions from EDA
- 2 questions from Machine Learning
- 1 question from Communicating Insights

For a real material-grounded RAG demonstration, the app must ingest this syllabus and sample notes, retrieve the corresponding source sections, generate questions, and display valid citations. That end-to-end pipeline is not yet implemented in the current prototype.
